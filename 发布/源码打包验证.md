# 源码候选打包验证

日期：2026-10-25。本文保留打包机制早期预演的可复现证据；列出的旧摘要仅说明历史测试，不作为当前发行包标识。当前发行以随包源码清单、构建对应记录和 SHA256SUMS 为准。

## 可检查行为与实现

| 行为 | 文件与实现 | 验证 |
|---|---|---|
| 只公开明确允许的源码与文档 | `script/package_release.py` 的 collect | 白名单拒绝意外产物；排除研究、验证、构建、账户配置及测试输出 |
| 公共说明不带本机路径 | 包内保留公开的 `README.md`、`README.en.md` 与 `assets`，配置仅纳入必要 plist/header | 文本检查拒绝本机用户绝对路径、私钥头及常见令牌字面值 |
| 提供完整固定引擎源码 | Git archive 固定提交，附公共 HEAD bundle | 已确认 HEAD 等于锁定提交、工作树无改动，bundle verify 通过 |
| 离线还原引擎版本身份 | `发布/准备离线源码.sh` | 在新解包目录核对引擎和 bundle 哈希；离线恢复后固定提交及 clean diff 通过 |
| 提供可复现归档 | 排序路径、固定 gzip/tar 时间、统一 uid/gid，逐文件清单 | 固定解包快照连续两次打包的 SHA-256 相同 |
| 源码能实际构建 | 隔离解包目录的 Release 构建 | `NTFS_BUILD_CONFIGURATION=Release bash script/build_and_run.sh --build-only` 退出 0；引擎和完整应用由随包源码重建 |

## 假设、未覆盖和回滚

此脚本是发布者使用的本地打包工具，不是秘密检测的完整安全产品。白名单和可检查文本规则不能保证发现所有形式的敏感信息；最终应再人工审查清单、公共说明和发行内容。

预演构建使用临时签名，没有进行公证、远端上传或真实盘验收。二进制与最终冻结源码的对应关系必须在最终一轮重新建立。公共 bundle 来自固定上游提交，不包括本项目私有 Git 配置或工作区历史。

最小回滚为停止使用打包脚本，保留输出证据；脚本只创建新候选目录，不覆盖应用，不修改系统，不批量删除文件。离线准备脚本仅在新解包树中恢复引擎 Git 元数据。
