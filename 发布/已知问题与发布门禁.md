以下保留此前版本的验证记录，本版实际执行范围以Release验证附件为准。历史系统扩展已完成发现、启用与新建镜像上的真实系统挂载。当时系统测试的准确结论是“8 项功能用例及身份拒绝后的直接正常分离均通过”。另已完成一块真实外部 NTFS 介质的指定目录读写、正常卸载与独立驱动复读闭环。0.1.1 还完成外部固定 USB 硬盘安全推出，以及新建镜像经 GUI 读写挂载、整盘弹出和离线文件摘要复核。两类验证范围独立，均不代表全部介质兼容性、完整产品验收或稳定版已经完成。

## 历史问题与当前真实介质状态

历史版本在错误介质身份被拒绝后，直接正常分离测试镜像返回资源忙（EBUSY），需额外只读挂载恢复。现已将激活保持为真实可用的只读状态，并在挂载阶段核验身份后才切换读写权限。最新签名版本验证错误请求不改变镜像，随后直接正常分离成功；这一阻断已修复。原失败记录保留，不再将额外恢复步骤计作修复证明。

仍保留一项系统输出观察：错误身份请求按预期返回 ESTALE，随后系统清理输出包含 Invalid argument；实际卸载与直接分离均成功。因此不能声称整个错误路径没有任何错误输出。

管理员挂载服务已实现，并已在验收环境完成系统授权。正式应用已在真实外部 NTFS 介质上完成只读和读写挂载，实际挂载类型为本应用的 `blntfs`，所有者为 root。只在新建的专用验收目录写入中文文本和 16 MiB 二进制文件，完成同步、即时哈希核对、重命名、扩展属性及 Finder 中文目录创建与重命名。随后由正式应用正常卸载，再由 Paragon 独立驱动复读测试文件、扩展属性和目录，并恢复原驱动挂载。该过程未格式化、修复或遍历用户已有文件；已有根目录项目仅核对名称仍存在，不能据此宣称整盘所有既有数据均经过哈希验证。

历史 TCC 拒绝已通过目录句柄传递修复并完成真实卸载验证：前台应用在用户上下文打开并核验事件目录句柄，经 XPC 传给助手；助手复核票据、介质、目录根路径和挂载实例后同步并正常卸载，无需为助手增加完全磁盘访问权限。已保留原失败记录，不把授权状态当作卸载成功。

同一助手进程、同一用户的正式应用合法挂载调用和正常卸载调用之间，错误签名只读探针被系统明确按签名要求拒绝；日志关联到该探针进程。修复后的探针正常输出观察并返回“未判定”，结论来自前后合法业务对照及系统拒绝日志，而非仅凭连接错误。跨用户实际隔离、助手进程重启恢复与更多故障场景仍需独立系统验收。

## 0.1.1 整盘推出的验证范围

管理员服务只执行身份核验、同步与正常卸载准备，最终 `DKIOCEJECT` 在前台应用取得授权后对同一只读设备描述符执行。真实外部固定 USB 硬盘已通过 GUI 推出；独立回读确认原介质身份不变、同盘无挂载、整个介质树的 `Open` 均为 `false`，应用显示“已安全推出，设备仍连接，可以断开”。该次验收未新增真实盘测试写入。

新建的展示镜像由 GUI 挂载为 `blntfs`，随后由 GUI 整盘弹出。原对象和镜像映射消失，65,573 字节测试文件经 `ntfscat` 离线复读 SHA-256 一致。该工具与本应用共用 NTFS-3G 核心，不代表 Windows 或独立 NTFS 实现验证。另有 314 项非设备回归通过。

固定硬盘物理连接保留不等于推出失败，但必须满足成功请求、原介质身份及容量、无挂载和全树关闭的共同条件；仅卸载或仅命令返回成功均不足。镜像和可移除介质仍要求原对象消失。应用只记住本会话成功回执，后续刷新发现重新挂载会撤销状态。


当前系统弹出集成另有 5 项真实镜像用例通过：错误介质身份拒绝；打开普通文件时拒绝并保留介质；关闭文件后正常弹出；额外原始设备句柄占用时约 3 秒有界拒绝；关闭该句柄后弹出未挂载整盘。两份新建镜像均正常释放。多分区物理盘、真实热拔插与断电不在这 5 项覆盖范围内。

## 完整产品与兼容性缺口

- Windows 独立读取、写回及文件系统检查尚未完成；同引擎复读不等于 Windows 兼容性验证，其他驱动复读也不能代替 Windows 检查。
- 主应用、菜单栏和设置已有实现；本轮13.7.4／14.0候选的窗口滚动、按钮触达与诊断导出已有分项实测。安装、权限配置、每卷偏好、登录启动、通知、失败恢复、移除服务和卸载应用仍需逐项完成并贯通验收，不能由这些分项替代完整主流程。
- 安全卸载不等于整盘弹出。0.1.1 已实测镜像对象消失和固定 USB 硬盘安全关闭两种成功结果；多分区物理盘、硬件重插与更多设备兼容性仍需分别验证。
- 校验、修复、格式化、权限与所有权、压缩/加密文件及其他 NTFS 特性需要独立实现或兼容性核验。尚未支持的能力必须明确显示状态，不能以占位按钮或有限预检充当完整功能。
- 真实硬件异常、长时间稳定性、性能对比、干净系统安装与人工体验验收尚不能由上述功能矩阵替代。目标范围保持不变，未完成部分继续作为开发和验收任务。

## 已知限制

- 0.3.0已交付Intel与Apple Silicon通用包：主程序、管理员助手和兼容前端最低macOS13，FSKit扩展最低15.4。15.4及以上走FSKit；13～15.3走用户自行安装批准的官方macFUSE。软件路径交付不等于Intel硬件、旧系统实体机和所有授权／挂载链均已通过。
- Apple虚拟机中的13～15.3兼容内核路径不可用；本轮13.7.4／14.0候选已验证明确拒绝，真实VFS仍未通过。15.4及以上的FSKit路径不受该VM拒绝规则禁用，实际结果须另行记录。
- FSKit 与宿主系统相关；本机曾出现已登记但未发现扩展、按 App 开关错误，正常重启和按类别启用后恢复。其他系统可能需要进一步排查。
