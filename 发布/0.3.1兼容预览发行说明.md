# 0.3.1兼容预览发行说明草案

日期：2026-11-05。当前为**0.3.1（构建8）私有候选，尚未发布**；源码已整合至[修复2347927](https://github.com/dososo/ntfs-writeflow/commit/23479279258f1887eada9c6d6b676d9583d92c05)；通用Release构建、正式签名与strict检查通过，未公证、未做本候选VM验收、未发布，旧系统真实读写完整链与最终分发核验仍待完成。公开下载继续使用[0.3.0](https://github.com/dososo/ntfs-writeflow/releases/tag/v0.3.0)，不提前提供0.3.1附件链接。

## 本轮四项用户变化

1. **修正旧版系统挂载发现与访问状态。** 15.4起、26以前，FSKit查询成功但漏列本应用时保留人工尝试入口，通过独立身份桥发现已启用模块。15.4～26.3只读改用系统原生NTFS，读写继续FSKit；26.4起两种模式均FSKit。旧FSKit受管读写必须核对扩展内部准备回执；只有内核可写、回执未知或失败时显示“写入未就绪”，不以绿色冒称可用。刷新只查询状态，不触发写入准备，等待查询后重新读取当前挂载实例，防止重挂后的迟到证明误用。自动管理继续要求系统明确报告扩展已启用。
2. **设置与诊断窗口内容可完整访问。** 长说明和错误可滚动，底部服务配置、刷新、导出按钮可达；诊断保存后可以读回。13.7.4、14.0、15.4已有真实界面分项验证，不能替代文件系统验收。
3. **明确提示Apple虚拟机旧后端限制。** macOS13～15.3的明确Apple虚拟机不能使用所需macFUSE内核路径，前台与助手返回具体原因，避免把运行库文件就绪写成可挂载。15.4起的FSKit／原生只读不按此规则禁用；未知型号不会被猜测为受限。
4. **拒绝特殊文件，保留失败和未知事务。** 不支持Interix字符设备、块设备、FIFO与socket，拒绝访问并在枚举中隐藏，不修改这些项的数据。原资源能力拒绝、原RO仍存活时的只读预检／身份拒绝会保留RO、锁存原错并禁止写入；普通镜像回归验证零数据写回和正常只读收尾，RO关闭或RW启动后的真实故障仍保持失败。探针超时、未决票据或收尾失败均不报告成功，也不删除凭据绕过。特殊项拒绝和不呈现setuid／setgid不代表旧FSKit内核安全标志已全部生效。

Intel／Apple Silicon通用包、最低macOS13及macFUSE兼容前端是0.3.0已有能力，本轮不重复列为新增。逐盘策略、登录后台管理、会话保护和写前预检继续保留；自动管理默认关闭。

## 已有证据与当前门槛

- 新内部准备协议、应用状态及真实AppModel回归各架构81项，挂起RPC后重挂实例重读12项，既有卷记录32项、弹出策略58项、挂载状态23项通过；完整应用／界面ARM和x86_64最低13目标严格类型检查通过。助手两架构完整核心回归通过，含18项私有参数、stdin句柄继承及有界未知结果检查。
- 原资源同步能力失败、nonce准备／被动状态、磁盘伪造同名属性拒绝、只读保留及错误锁存等真实普通镜像回归在ARM／Rosetta通过。它们没有使用真实FSBlock资源或系统挂载；不能据此宣称VM、Intel硬件或实体盘通过。
- 13.7.4（22H420）／14.0（23A339）ARM客体完成安装、签名／Gatekeeper和窗口／诊断导出分项；macFUSE内核路径不可用，真实VFS未通过。13.7.4授权记录与系统job不一致，助手加载及XPC未验收；14.0只确认服务登记、未实际运行。
- 15.4旧候选已有身份桥接、扩展关闭拒绝和`b41b501`原生只读GUI分项通过；同候选RW创建返回`EROFS`。后续`f9caabd`虽进入内部RW，但资源登记／刷新被拒，实际创建`EIO`且正常卸载失败；公开IOKit例外和普通用户身份对照均未解决。**构建8的根FD握手及完整GUI读写、同步、忙句柄、正常卸载、重挂复读尚未客体验收。**
- 阶段四[修复2347927](https://github.com/dososo/ntfs-writeflow/commit/23479279258f1887eada9c6d6b676d9583d92c05)已修复原先的预检收尾P1并完成独立只读审查：仅旧系统分支把只读quickcheck、身份复核及后端包装器创建前置到原RO关闭之前，拒绝时锁存原错并保RO。暂持包装器未转移时精确清理，成功后才消费RO并开启RW引擎；原RO关闭失败或RW引擎开始后的真实错误仍拒绝，不把空handle的同步改成成功。第一份构建8因该P1阻断，证据保留、制品不可用，不以相同版本号混作阶段四候选。
- 阶段四三个runner双架构及六目标类型检查全0，独立审查未发现确定P0／P1；这些仍不是新候选真实FSBlock、root或VM验收。
- 原公证配置在数据保护钥匙串（DP）中存在，当前宿主锁屏使其无法取用；不能写成配置丢失或要求重建。阶段四构建8已完成正式签名和strict校验，公证、装订、离线源码对应与附件回下载核验仍须完成，旧包公证不能代替新候选。

旧FSKit读写实测未全部保留`nosuid`／`nodev`／`nobrowse`，不能依赖传入选项提供对应内核保护。公开KOIO回退属性的有效位仍失败，新增KOIO能力的客体安装／启用实验待当次明确授权，不属于本私有候选已交付能力。详细函数、失败对照、命令和六项说明见[可核验说明](0.3.1可核验说明.md)。

13.7.4／14.0的CI来源客体初始SIP disabled、Authenticated Root enabled、Gatekeeper enabled；14.0正常Recovery启用SIP被Apple个性化签名请求错误132拒绝，未恢复。这些结果不能代表默认安全实体Mac，也不能代表Intel硬件；原镜像标签13.6不等于实际验证13.6。

## 安装、升级与回退

macOS15.4起不需要为本应用安装macFUSE；按应用提示完成FSKit扩展及管理员服务授权。13～15.3实体兼容路径需要本人安装批准[官方macFUSE](https://github.com/macfuse/macfuse/wiki/Getting-Started)，Apple Silicon可能需按官方流程调整启动安全；本应用不捆绑该运行时、不自动改变系统安全设置。

当前私有候选不作为正式升级包提供。已有产品升级或回退前，应关闭自动管理、等待事务结束、正常卸载并通过产品移除旧服务后退出，再替换同一固定位置应用。失败或未知时保留诊断、票据、锁及回执，不强制清理；回退0.3.0仍有其已知限制。详见[安装与卸载](安装与卸载.md)。

Intel实体机、旧系统实体兼容后端、真实登录／跨用户、实体盘多轮、Windows、睡眠、异常拔插、掉电与长期压力仍待验。[Issue #3](https://github.com/dososo/ntfs-writeflow/issues/3)的macOS27.2实体盘原环境尚未复测，保持打开。
