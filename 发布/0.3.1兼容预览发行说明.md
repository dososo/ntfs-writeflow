# 0.3.1兼容预览：让状态更清楚，把实际阻断逐步修掉

版本0.3.1，构建11，2026-11-06。这个版本继续回应大家对旧系统、数据可靠性和日常使用的反馈，仍作为兼容预览提供。[下载DMG／ZIP及核验附件](https://github.com/dososo/ntfs-writeflow/releases/tag/v0.3.1)。

**Intel通用包、最低macOS13和macFUSE兼容后端是0.3.0已有能力；逐盘自动管理来自0.2.0。** 本版完善已有流程，没有把这些再次列为首次新增。

## 你会感受到哪些改变

| 原来遇到的问题 | 0.3.1做了什么 | 怎么用、还有什么限制 |
| --- | --- | --- |
| 系统查询没有列出模块，手动入口直接被挡 | 15.4起，只有查询成功但状态未知时，可以由用户手动交给系统继续核验 | 正常启用扩展和服务后手动选择挂载；系统明确关闭、查询错误或等待时仍停止，自动管理不放宽。允许尝试不等于已经启用 |
| 界面显示可写，内部其实还没准备好 | 旧FSKit路径要完成内部准备才显示可写，刷新／重挂不会套用旧状态 | 看到“写入未就绪”先停止继续写，保留错误；不把界面绿色当作完整数据验收 |
| 写入前检查拒绝后，还想保留只读访问 | 在原只读仍存活时完成能力、预检和身份检查，拒绝则保留可读 | 只覆盖这一阶段；原RO关闭或RW开始后发生的真实错误不保证保RO |
| 旧系统卸载时卡在收尾 | 补系统漏回调的正常收尾，区分目录缓存与真实文件占用，保留同步和关闭错误 | 正常卸载，先处理占用；不强制关闭。系统是否把最终关闭错误返回App仍有限制 |
| 设置和诊断太长，底部入口难用 | 窗口可滚动，长错误可查看，配置和导出入口可达；修复源码首次构建及验收工具入口 | 普通使用不需要编译源码；需要研究时可取同版完整源码与核验材料 |

对应反馈与各版用法见[用户反馈与版本迭代对照](用户反馈与版本迭代对照.md)。自动管理仍默认关闭；手动卸载后不自动重挂，遇竞争驱动、身份或会话不明时暂停。

## 哪些Mac走哪条路径

| 系统 | 只读 | 读写 | 前置 |
| --- | --- | --- | --- |
| macOS13～15.3 | macFUSE兼容后端 | macFUSE兼容后端 | 本人另装并批准官方macFUSE，配置管理员服务；Apple虚拟机不支持这条内核路径 |
| macOS15.4～25.x | 系统原生NTFS | 本应用FSKit扩展 | 启用扩展，全部挂载经管理员服务 |
| macOS26.0～26.3 | 系统原生NTFS | 本应用FSKit扩展 | 只读／读写都经管理员服务；实际系统未验 |
| macOS26.4及以上 | 本应用FSKit扩展 | 本应用FSKit扩展 | 启用扩展，按磁盘权限使用服务；本机26.6.2当前仍挂载失败 |

这是实现范围，不是全部组合的实机支持承诺。macFUSE不随包分发，旧系统Apple Silicon可能需要本人按官方流程批准组件并调整启动安全；应用不会自动修改系统保护。系统原生只读不经过NTFS-3G，其他两条后端使用随包引擎。

## 已测到什么，还缺什么

| 范围 | 真实结论 |
| --- | --- |
| 当前构建11分发 | App与DMG通过签名、公证、装订和Gatekeeper，两种容器的21文件一致；最终源码、离线重建和下载校验记录见同版Release附件 |
| 历史构建10／macOS15.4 ARM客体 | 受控镜像完成中文写读、同步、忙句柄拒绝、正常卸载、只读重挂复读及扩展内部收尾；不能转记成构建11同包实测 |
| 本机26.6.2／构建11／真实盘 | 请求进入系统后返回69，用户代理扩展集合未找到目标短名；未观察到我方模块启动，未新增测试文件，没有实盘读写通过结论 |
| 13.7.4／14.0 ARM虚拟机 | 安装、窗口、诊断保存读回和平台限制提示有分项；兼容内核VFS未过，13助手加载及XPC未验收 |

新11的手动入口和自动门槛有双架构开发回归；它们不代替真实系统挂载。旧构建9仍因停用错误16判完整失败；历史7／8及本轮细节保留在[可核验说明](0.3.1可核验说明.md)，没有因宣传改绿。

本机安装时还遇到过模块漏列和按App开关回关。[macFUSE维护者](https://github.com/macfuse/macfuse/issues/1194#issuecomment-5470510841)对按App入口提出过按类别启用的建议；本机按类别仍只有Apple模块，所以不能据此认定本应用根因或宣称已修复。PluginKit登记或保存的启用ID也不代表运行时授权。

仍未验：Intel实体、13／14实体兼容链、26.0～26.3实际系统、Windows互操作、掉电／异常拔插、长期压力、真实登录／跨账户与实体多轮。26.4只有镜像准备。13／14客体初始SIP disabled，14恢复SIP请求被Apple错误132拒绝，不能代表默认安全实体Mac；Rosetta也不是Intel硬件证据。

**性能没有新成绩。** 历史大文件功能记录不是本版延迟或吞吐承诺，没有Paragon同条件实测对比。旧FSKit部分系统安全标志未全部保留，特殊文件另有限制；完整边界保留在[已知问题](已知问题与发布门禁.md)和可核验说明。

[Issue #3](https://github.com/dososo/ntfs-writeflow/issues/3)的macOS27.2原实体盘环境仍待复测，保持打开。相同退出码不代表和本机26.6.2是同一根因。

## 升级、使用与回退

1. 关闭自动管理，等待正在进行的操作结束，正常卸载自有卷。
2. 在旧应用设置移除挂载服务并退出，再替换固定位置应用；不要同时运行多处副本。
3. 按[安装说明](安装与卸载.md)重新批准扩展和服务，再核对磁盘状态。遇到系统拒绝或未知状态时停止，保留诊断，不强制卸载、不删除锁或凭据绕过。

回退沿相同步骤。下载同版DMG或ZIP，核对`SHA256SUMS.txt`；完整对应源码和核验附件同页提供，分发信任与磁盘兼容性分别看待。
