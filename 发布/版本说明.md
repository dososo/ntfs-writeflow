## 0.3.0（构建 6）兼容预览版 · 2026-11-05

- 根据用户反馈交付 Intel／Apple Silicon 通用应用，主程序、助手与兼容前端最低 macOS 13，FSKit 扩展最低15.4。
- 解决旧系统 Observation、窗口和 `funmount` API 阻断；13～15.3 接入用户自行安装批准的官方 macFUSE，提供真实 NTFS 读写回调。
- 旧系统使用 root 私有一次性目录、租约及身份复核正常卸载；26 及以上保留按文件句柄卸载。
- 整盘互斥随实际后端进程存活，收尾状态持久化；写回／关闭失败、异常退出、未知回执拒绝成功与后续弹盘。
- 保留0.2.0逐盘策略、原生事件、登录后台管理、会话保护与只读预检。自动管理默认关闭。

本轮运行 ARM 与 Rosetta 的真实文件镜像回调、故障注入、官方运行库 ABI／生产参数解析和通用包构建。没有旧系统内核挂载与 Intel 实机验收，不把模拟、最低目标编译或签名公证替代目标硬件证据。macFUSE 不随包分发；Apple Silicon 旧系统可能需要用户手动调整启动安全和批准内核扩展。Issue #3 的 macOS 27.2 原环境复测仍待完成，保持打开。完整更新、安装与限制见[兼容预览发行说明](0.3.0兼容预览发行说明.md)与[可核验说明](0.3.0可核验说明.md)。

## 0.2.0（构建 5）功能预览版 · 2026-11-05

本预览版汇总上一轮新增能力，并加入 Issue #3 的挂载会话候选修正。默认关闭自动管理，供有备份的测试环境试用；本次公开预览不代表实体盘复测或稳定兼容性验收通过。

- **逐盘自动挂载**：保存关闭、只读、读写策略；默认关闭，缺少可靠介质身份时禁用。原生磁盘事件驱动，启动时已有盘不追溯接管，手动卸载或弹出后不自动重挂。
- **登录与后台运行**：可设置登录启动，关窗保持运行，明确退出停止。登录项被系统撤销时暂停自动管理。
- **会话保护**：需主动确认当前会话；锁屏、睡眠或会话失活撤销旧确认，唤醒及普通激活不会自动重新授权。
- **挂载前保护**：遇到竞争驱动、查询不完整或介质身份变化时停止；写前在同一资源进行只读预检，拒绝脏卷、休眠和日志／I/O 错误。
- **状态与诊断**：修复消失卷残留、迟到查询及旧事件误触发；提供默认关闭、最长六小时的本地限时会话日志。
- **Issue #3 候选修正**：固定挂载子进程采用可信连接用户的登录审计会话，并保留用户扩展发现所需的 `SUDO_UID`。已补调用边界回归；macOS 27.2 实体 USB 盘的 TCC 故障仍需原环境确认，不能把镜像成功当作问题解决。

本次采用明确保留待验场景的预览发行范围；实体接入二十轮、真实登录、跨账户及无竞争环境仍待验，作为后续稳定支持的门槛。Intel 只有交叉构建证据，macOS 15.4 完整应用仍阻断；不增加目标系统支持或 Paragon 性能承诺。预览范围与升级步骤见[预览发行说明](0.2.0预览发行说明.md)。详见[候选验收记录](0.2.0验收记录.md)与[Issue #3 候选验收](Issue-3候选验收.md)。

## 0.1.2 安全与诊断预览 · 2026-10-29

版本 0.1.2，构建号 3。根据公开评论中的可靠性疑问，修复卸载关闭阶段错误被忽略的问题，并让验证范围与诊断更明确。

- C 桥的关闭接口返回负 errno，并明确所有返回路径都会消耗句柄；捕获打开文件清理、关闭阶段同步和引擎最终关闭错误。
- FSKit 卸载在关闭失败时报告 notReady，不重新打开为看似正常的只读卷。FSKit 的 unmount 回调无 throws，因此此修复不等于系统一定拒绝卸载，也不能代替 Windows、断电或所有设备兼容性验证。
- 卷详情显示重要数据备份及 Windows 休眠/快速启动风险；诊断显示当前版本、构建号及 NTFS-3G / FSKit 架构，历史测试不再表示当前运行已通过。
- 自动挂载、Intel、旧系统和性能对比仍在后续计划；当前仅支持 Apple Silicon、macOS 26 及以上。

本轮314项非设备、8项签名门禁、47项引擎检查、FSKit适配回归、8项系统镜像及5项镜像弹出用例通过。分发公证与校验见Release附件；没有测试的场景保持待验收，不承诺全面稳定。


## 0.1.1 公开预览版 · 2026-10-25

版本 0.1.1，构建号 2。本版本补齐应用内安全弹出整盘及结果反馈，并准备与 onedict 展示结构一致的中英文首页、应用图标和真实界面截图。公开仓库为 [dososo/ntfs-writeflow](https://github.com/dososo/ntfs-writeflow)，下载与完整对应源码见 [v0.1.1 预览版](https://github.com/dososo/ntfs-writeflow/releases/tag/v0.1.1)。Release 标为预发布，当前已知限制继续保留。

### 安全推出

先核对原介质身份和同盘分卷，由管理员服务验证前台提供的挂载根句柄并同步、正常卸载。随后前台应用取得精确整盘设备的只读授权，对持续持有的同一描述符请求推出；不通过后台进程重新打开设备，不强制卸载或推出。系统可能要求本人在 macOS 窗口使用 Touch ID 或密码认证；取消时如实报告分卷可能已经卸载，整盘尚未确认退出。

推出成功分为两种结果：镜像和可移除介质必须确认原对象消失；外部固定 USB 硬盘若原本及当前均明确为不可机械弹出、不可移除，允许仍保留物理连接，但须核对原两层介质身份和容量未变、同盘无挂载、整个介质树的打开状态均为关闭，才返回“已安全推出，设备仍连接，可以断开”。仅卸载、仅请求返回成功或仅设备名相同均不足以得到此回执。应用刷新发现重新挂载时，会撤销本会话已推出状态。

实际外部固定 USB 硬盘已通过应用操作和独立系统回读；本轮弹出验收未新增真实盘测试写入。另通过专用测试镜像的 GUI 读写挂载、GUI 整盘弹出、原对象和镜像映射消失，以及 65,573 字节测试文件的 `ntfscat` 离线全量 SHA-256 复核。`ntfscat` 与本应用共享 NTFS-3G 核心，不能当作独立 NTFS 实现或 Windows 交叉验证。314 项非设备回归通过，覆盖入口保护、结果回执、介质身份、句柄、系统授权边界与既有挂载服务策略。它们不替代硬件异常、Windows 或长期稳定性验证。


当前系统弹出集成另有 5 项真实镜像用例通过：错误介质身份拒绝；打开普通文件时拒绝并保留介质；关闭文件后正常弹出；额外原始设备句柄占用时约 3 秒有界拒绝；关闭该句柄后弹出未挂载整盘。两份新建镜像均正常释放。多分区物理盘、真实热拔插与断电不在这 5 项覆盖范围内。

### 分发与对应源码

该版本应用已完成正式签名、公证、票据装订及本机 Gatekeeper 核验。DMG 因公开下载说明更新而重新打包并独立公证；内嵌应用与已验收构建一致。Release 同时提供完整对应源码、`分发验证摘要.json`、`构建对应记录.json`、`源码清单.json` 及 `SHA256SUMS.txt`。本次公开发布只更新文档与分发容器，没有改动应用代码或构建资源。
