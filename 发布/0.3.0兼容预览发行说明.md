# 0.3.0 兼容预览发行说明

日期：2026-11-05。版本 0.3.0，构建 6。根据用户关于 Intel、旧系统、自动挂载和数据可靠性的反馈，本版交付双架构应用、旧系统实际运行后端及配套保护，继续作为预发布提供。

## 这次具体更新了什么

- **Intel 与 Apple Silicon 同包**：主程序、管理员助手、文件系统扩展和兼容前端均包含 `arm64`、`x86_64`。发行门禁逐个检查切片和最低系统，缺组件或混合架构即拒绝发行。
- **最低系统降至 macOS 13**：移除主程序对较新 Observation 和窗口 API 的硬依赖。macOS 13／14 使用保持后台启动与关窗行为的 AppKit 窗口桥接；新版系统保留原窗口路径。
- **macOS 15.4 及以上使用 FSKit**：完整应用解决了 `funmount` 仅在 26 及以上可用的运行阻断；扩展最低系统为 15.4，并弱链接主程序中的 FSKit。
- **macOS 13～15.3 增加真实 macFUSE 后端**：复用随包 NTFS-3G 引擎，接入文件读写、追加、目录、重命名、属性、截断、同步与关闭回调。用户需自行安装并批准官方 macFUSE；本应用不捆绑或自动安装其运行时。
- **旧系统正常卸载**：采用 root 私有一次性挂载目录、完整介质与挂载身份复核、目录租约和正常路径卸载。macOS 26 及以上继续使用原有按文件句柄卸载。旧系统方案不具备后者对另一个 root 进程绕过仲裁后重挂同一路径的原子保证。
- **兼容后端的写回闭环**：整盘互斥锁随实际后端进程持有；最后关闭状态写入持久回执。同步失败、异常退出、未知／旧回执或进程仍存活时，不报告卸载成功，不继续弹盘，不强杀后端。服务重启后也复核回执。
- **设备与代码来源保护**：前台授权取得精确模式的原始分区句柄，后端不按设备名重新打开；运行库和兼容程序复制到 root 私有目录后严格验签，再启动。仅兼容前端使用加载官方第三方库所需的专用权限。

0.2.0 的逐盘关闭／只读／读写策略、原生磁盘事件、登录启动、关窗继续运行、会话撤销、写前只读预检和本地诊断全部保留。自动管理仍默认关闭，启动时已有盘不接管，手动卸载后不重挂。历史截图和 36 秒影片展示较早版本，不是本版全平台验收录像。

## 运行路径与验证范围

| 系统与架构 | 本版交付路径 | 本轮验证及限制 |
| --- | --- | --- |
| macOS 26 及以上，Apple Silicon | FSKit；26 起使用文件句柄卸载 | 当前 26.6.2 原生构建与回归；不推断每个新版本都通过 |
| macOS 15.4～25，两种架构 | FSKit；私有目录与租约下正常路径卸载 | 完整双架构最低目标构建及身份／故障回归；目标系统内核挂载待验 |
| macOS 13～15.3，两种架构 | 用户安装官方 macFUSE，随包兼容前端与 NTFS-3G | 原生及 Rosetta 真实文件镜像回调、官方库 ABI／选项解析、错误注入；目标系统完整授权／挂载链待验 |
| Intel 硬件 | 通用包中的 x86_64 切片 | 已真实 Rosetta 执行，不等于 Intel 硬件验收 |

每块整盘同时只允许一个兼容后端会话，不能同时通过兼容后端挂载同盘多个分区。其他工具在普通 `/Volumes` 路径挂载的卷，旧系统下应先用 Finder 或原工具正常卸载；应用不会用无凭据的路径替它卸载。后台自动管理仍会因竞争驱动、状态不完整或会话未确认而暂停。

测试创建的新 NTFS 普通文件镜像执行了真实生产回调与引擎读写，包含中文名称、追加、只读整镜像摘要不变、脏卷拒写、跨父进程退出持锁和收尾写失败。官方 macFUSE 库测试使用只读展开的原始已签名制品，只做 ABI 与真实选项解析；没有安装驱动、加载内核扩展或执行 macFUSE 系统挂载。用当前系统自建 HFS+ 镜像验证的正常路径卸载，只证明相应系统调用原语，不等于旧系统 NTFS 完整链通过。详细对应关系见[可核验说明](0.3.0可核验说明.md)。

仍待：Intel 实机、macOS 13～15.3／15.4 目标系统，macFUSE 内核批准后的真实 Finder／root 助手闭环、实体接入二十轮、真实登录和跨账户、干净机安装卸载、Windows 复读检查、掉电／异常拔插、睡眠和长期压力。没有新增 Paragon 速度承诺。

[Issue #3](https://github.com/dososo/ntfs-writeflow/issues/3) 的 macOS 27.2 实体盘 TCC 故障仍待报告者复测；0.2.0 的会话候选修正随本版保留，问题保持打开。

## 安装与升级

从 [v0.3.0](https://github.com/dososo/ntfs-writeflow/releases/tag/v0.3.0) 下载通用 DMG／ZIP，核对同页 `SHA256SUMS.txt`。完整对应源码附件包含固定引擎与 macFUSE 头文件，不包含 macFUSE 运行库或驱动。

升级前关闭自动管理，等待操作返回，保存文件并正常卸载所有自有卷；移除旧应用登记的管理员服务并退出，备份旧包后替换到固定安装位置。不要同时启用多个应用副本。重新配置服务并核对版本为 0.3.0（6）。详细流程见[安装与卸载](安装与卸载.md)。

macOS 15.4 及以上启用本应用 FSKit 模块，无需为本应用安装 macFUSE。macOS 13～15.3 则按 [macFUSE 官方安装说明](https://github.com/macfuse/macfuse/wiki/Getting-Started)自行安装并批准其系统组件；Apple Silicon 在这些系统上可能需要本人在恢复模式调整启动安全并批准内核扩展。这是可选第三方运行时的系统要求，应用不会代办或自动更改设置。不愿进行该调整时，请保留系统只读访问或使用适合当前系统的方案。

兼容后端报告收尾失败时，保留应用、凭据和诊断，停止继续写入或弹盘；不要手工删除 root 私有缓存和锁文件来绕过错误。安全移除介质后，应在 Windows 检查卷并保留失败信息。回退代码不会自动清除失败回执，也不修复卷。

回退须先正常卸载、停止自动管理并移除服务。macOS 26 的 Apple Silicon 用户可恢复 [0.2.0](https://github.com/dososo/ntfs-writeflow/releases/tag/v0.2.0)；其他系统不能运行旧版，可停止使用预览版并恢复原有只读或其他工具路径。无需修改用户盘数据。公证、下载校验和源码对应关系仅以本次 Release 验证附件为准。
