# 0.2.0 功能预览发行说明

日期：2026-11-05。版本0.2.0，构建5。发行标记为预发布，目标为Apple Silicon、macOS 26及以上；本机验证环境为macOS 26.6.2。不增加Intel、旧系统或每个新系统小版本的兼容保证。

## 本次新增

- 逐盘保存关闭、只读或读写策略；自动管理默认关闭，缺少可靠设备身份时禁用策略保存。
- 采用原生磁盘事件；启动时已有盘不追溯接管，手工卸载或弹出后不自动重挂。
- 可选登录启动、关窗保持运行；退出应用停止管理。
- 当前会话需主动确认；锁屏、睡眠或工作区失活撤销旧确认，恢复后不会自动重新授权。
- 发现其他驱动、身份变化或清单不完整时暂停；写入前在同一资源进行只读预检。
- 修复消失卷残留、迟到查询和旧授权事件误触发；本地限时会话观测默认关闭，最长六小时。
- 管理员挂载固定子进程采用可信连接用户的会话上下文，同时保留扩展发现所需的SUDO_UID。这是[Issue #3](https://github.com/dososo/ntfs-writeflow/issues/3)的候选修正，仍待macOS 27.2实体盘确认。

## 预览范围与未验收场景

本次允许在明确保留未测项目的范围内公开功能预览，不把此前候选记录的待验门槛勾成通过。实体盘接入二十轮、真实登录、跨账户、无竞争驱动环境、干净机安装卸载、Windows复读与检查、掉电／异常拔插、长期压力和真实Paragon对比仍待验。Intel仅有交叉构建及本机Rosetta证据，macOS 15.4完整应用仍受系统API限制。

本机安装了其他NTFS驱动，生产自动管理会按设计暂停；注入模型与新建镜像通过不能证明无竞争环境的自动接管已通过。当前系统未提供原子锁屏屏障，已接受的挂载事务不会被撤销事件强杀；详见[会话安全边界](0.2.0会话安全续验.md)。

Issue #3的故障尚未在原环境复验，保持打开。公证证明分发信任，不证明实体盘、TCC责任归属或文件内容正确。新版本的原始测试、签名、公证与容器对应记录见Release的验证附件，不将旧版本证据当作本版实际执行结果。

## 安装、升级与回退

下载[0.2.0预览版](https://github.com/dososo/ntfs-writeflow/releases/tag/v0.2.0)的DMG或ZIP，校验同页SHA256SUMS.txt。完整对应源码包包含固定依赖和离线恢复材料；GitHub自动生成的源码压缩包不能代替该附件。

升级前关闭自动管理，等待已接受操作返回，保存文件并正常卸载自有卷；在旧应用设置移除已登记的管理员服务，正常退出后备份旧应用。将新应用放入个人Applications目录，再按[安装说明](安装与卸载.md)启用扩展并重新配置管理员服务，核对实际版本为0.2.0（5）。不要同时保留多个可被系统发现的已启用应用副本；旧包备份采用压缩归档保存在应用安装目录以外。

首次仅使用有备份的测试卷，主动确认会话后再逐盘选择策略。不要求关闭SIP、降低启动安全、修改设备节点权限或向后台服务增加完全磁盘访问权限。系统拒绝时停止，不反复接管或强制卸载。

回退时按同样顺序关闭自动管理、等待事务结束、正常卸载与移除服务，再恢复[0.1.2](https://github.com/dososo/ntfs-writeflow/releases/tag/v0.1.2)并重新配置。无需改动用户盘数据。候选代码映射、测试、推断和未覆盖范围见[Issue候选验收](Issue-3候选验收.md)与[功能验收历史](0.2.0验收记录.md)。
