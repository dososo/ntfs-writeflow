# 测试子进程中断与镜像恢复验收

本入口只创建本轮三份128MiB普通文件镜像，逐份执行；不接受外部设备或镜像参数。每份先经生产DiskService实际读写挂载、写入并同步65,573字节基准，再正常卸载。事件、测试硬件标识、批准规则版本、竞争clear及活动会话属于注入，未停用本机真实第三方驱动。

## 三个精确检查点

| 阶段 | 实际中断位置 | 不代表什么 |
| --- | --- | --- |
| 事件提交前 | 已构造真实AppModel和隔离政策，尚未调用processAutoEvent | 不是批准回调进行中 |
| 查询回包挂起 | 已完成一次真实DiskService.record，测试闭包尚未把结果交回AppModel | 不是声称diskutil仍在执行 |
| 系统挂载确认后、协调器未回包 | 生产DiskService.mount已返回，实际blntfs及RW已核实；测试mount闭包尚未返回协调器 | 不是声称内核mount调用仍在进行中 |

父进程从子进程只读管道取得精确PID、随机令牌与阶段握手，才对自己创建的Popen对象执行SIGKILL并核对退出码为-9。没有全局pkill、没有使用报告中的任意PID发送信号，不终止真实桌面应用、FSKit宿主或系统磁盘进程。握手失败或超时时，只清理自己仍活动的子进程，样本保持失败。

中断后父进程重新按本次镜像路径查映射、虚拟属性、容量和原设备；恢复子进程还核验真实IOMedia登记ID。前两阶段必须仍未挂载且完整镜像摘要未变；第三阶段必须与确认检查点的挂载位置一致。恢复只允许本轮当前用户在生产私有随机路径上的真实blntfs挂载，随后调用生产正常卸载、只读重挂、基准全量复读及正常卸载。整个只读周期前后还比较完整128MiB镜像摘要。

清理单独记账：已知自有blntfs可经生产正常卸载释放，未知供应商、身份变化或异常路径不接管；精确路径再次查询后才正常detach。失败不使用强制选项，不用成功清理掩盖原样本失败，后续阶段停止。镜像和日志保留，不批量删除。

## 无设备检查

```sh
/usr/bin/python3 Tests/System/中断恢复纯测试.py
/usr/bin/python3 Tests/System/镜像失败清理测试.py
```

第一条含十一项测试，覆盖握手不匹配、真实自有计算子进程的精确终止、输出上限、期限、损坏握手原始证据保留、虚拟/容量/映射拒绝及检查点状态边界。第二条复用既有七项清理拒绝检查；均不挂载、卸载或写入设备。只有第一条测试中自己启动的短暂Python计算子进程被SIGKILL。

## 编译与正式签名

在正式仓库根目录、当前源码冻结后执行，不能沿用早期编译物冒充最新源码：

```sh
mkdir -p build/0.2.0
xcrun swiftc -target arm64-apple-macos26.0 -swift-version 6 -warnings-as-errors \
  -import-objc-header Configuration/App-Bridging-Header.h \
  Sources/Core/*.swift Sources/HelperShared/*.swift Sources/App/Services/*.swift \
  Sources/App/AppModel*.swift Tests/System/中断恢复子进程.swift \
  -o build/0.2.0/中断恢复子进程
codesign --force --options runtime --timestamp --identifier com.blteam.ntfsworkbench \
  --sign "${DEVELOPER_ID_APPLICATION:?本机同团队有效证书}" build/0.2.0/中断恢复子进程
```

另须已有固定引擎`mkntfs`、签名的唯一扩展清单查询工具及只读IOMedia身份工具。编译不是执行设备测试；运行前应取得本轮镜像验收窗口，确认本机唯一启用扩展位于标准安装路径。父入口会自行复核该前置条件；不注册服务、不改变扩展权限或助手白名单。

```sh
python3 Tests/System/中断恢复验收.py
```

结果位于唯一`build/0.2.0/中断恢复-*`目录，包含准备/中断/恢复的输出、每个固定系统命令、退出码、实际终止PID、检查点原始输出、文件与完整镜像摘要及映射清理结果。宿主保留20GiB之外再检查三份镜像所需空间。运行时记录实际子进程与已安装扩展摘要；编译源码变更后须重新记录编译元数据。
