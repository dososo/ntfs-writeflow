# 系统托管镜像回归

这些测试只创建全新镜像，不接受现存镜像或设备路径。需要已构建的 NTFS-3G 工具、Xcode 命令行工具，以及安装在 `~/Applications/NTFSWriteFlow.app`、已由用户启用的正式扩展。使用普通用户运行，不使用 sudo。

```sh
python3 Tests/System/系统镜像回归.py
```

脚本先用已有的签名查询工具 `build/system-tests/扩展清单复核` 确认唯一启用扩展，再编译只读 IOKit 身份查询工具。每次附加与挂载均核对本轮镜像路径、虚拟设备、整盘类型和 IOKit 底层容量，挂载命令携带当前介质登记身份。不会按历史 disk 编号操作，也不会操作同设备上的其他挂载点。

覆盖项：

- 错误介质登记身份必须被拒绝，整镜像哈希不变，再重新附加验证正确身份读写。直接正常分离另列附加检查；若资源忙，仅本轮自有且重新核验映射的镜像允许正确身份只读重新加载恢复，附加检查仍记为未通过。
- 8 线程、320 个小文件：创建、同步、重命名、复读与枚举。
- rename 覆盖保留原打开句柄；删除后句柄继续读写同步。
- 64 MiB 空洞读取零，实际分配量低于 2 MiB。
- 240 个中文字符的长文件名、组合音符、表情、空格引号，以及 4352 字节扩展属性。
- 底层镜像以可写方式附加，只将文件系统挂为只读：创建和截断拒绝、卸载分离后整镜像哈希不变。
- 64 MiB 小镜像写至 ENOSPC；验证已有记录完好，删除填充文件后可以再写，卸载重挂载内容仍在。
- 6 GiB 镜像中实际写入 4 GiB + 17 MiB + 123 字节。每 4 MiB 数据块含偏移派生内容，检验首次及卸载重挂载后的全量哈希，避免重复模式掩盖地址回绕。

创建镜像前检查宿主盘剩余空间，要求镜像容量之外至少保留 20 GiB；大文件与磁盘满写入期间继续检查。小镜像填满不等于填满宿主文件系统。

结果和每个外部命令的参数、输出、退出码保存在 `Tests/System/结果/`，不进入版本库。镜像与挂载点位于本轮 `/private/tmp/blntfs-回归-*` 私有目录。所有测试结束后正常卸载并分离；通过组只删除对应的一个镜像文件，失败组保留镜像。不会递归删除目录或强制分离。若设备映射变化、出现其他挂载点、正常卸载失败，则停止并保留现场，不能直接复制结果中的历史设备名进行清理。

不覆盖真实介质、断电、拔插、睡眠唤醒、长期并发、Windows 独立实现复读或性能基准。本测试也不覆盖普通文件 `FSPathURLResource` 的系统托管挂载，因为本机 mount 工具对同时声明块设备与路径资源的模块优先构造块设备。

## 稀疏缺陷定位

```sh
bash Tests/System/稀疏后端回归.sh
```

此脚本只新建普通镜像并调用 C 桥，不调用 mount 或 hdiutil。驻留小文件与非驻留文件跨越 64 MiB 写入后，分别验证分配量与空洞读零；同时覆盖先扩展逻辑长度再写末尾，以及预分配后扩展逻辑长度的未初始化区域读零。
