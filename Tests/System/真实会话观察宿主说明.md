# 真实会话观察宿主

这个独立 GUI 工具直接链接当前生产 `Core`、`Services` 和 `AppModel`，使用真实 AppKit、工作区及生产会话监控的九类信号。它只验证会话确认和撤销，不代表正式安装应用、真实登录启动或实体盘验收。

## 构建与本轮运行状态

应用包：`build/system-tests/真实会话观察宿主.app`。

源码：`Tests/System/真实会话观察宿主.swift`。

已通过 Swift 6 严格编译、应用包信息文件检查及本地临时签名严格验证。工具未公证，不是发布候选。构建来源及各输入源码指纹位于 `build/system-tests/真实会话观察宿主-构建来源.json`。

准备阶段没有启动工具、没有开始计时。随后主线程与队长协调，队长已完成本轮一次手动锁屏、解锁、再次确认和结束观察。完整记录位于 `build/system-tests/真实会话观察-1793257335/`，不是未经用户协调的自动会话操作。

## 隔离边界

- 自动管理初始为关闭，界面没有开启入口；定时检查若发现开关打开、存在磁盘监控或发生磁盘边界调用，会停止观察。
- 仅调用生产 `startAutomaticSessionMonitoring()`，不调用磁盘监控入口。关闭或结束观察调用生产 `stopMonitoring()` 清理。
- `AutoMountRuntime` 的磁盘读取、挂载边界全部抛错；环境返回阻断，挂载许可返回假，登录状态使用隔离值，不注册或修改登录项、管理员服务、扩展。
- 保留生产 `DiskService` 初始化，它会创建被动 Disk Arbitration 句柄并设置队列；没有注册磁盘事件回调，没有枚举或执行 `snapshot/record/mount/unmount`。不能称为完全没有创建任何 DA 句柄。
- 测试默认值的自动开关为假、规则数据为空、写入不落盘；没有读取或改写生产自动挂载策略。
- 日志只写到应用包所在的 `build/system-tests` 下新建的本轮目录。没有向系统通知中心发送伪事件，没有主动锁屏、睡眠、切用户或注销。

## 队长手动验收步骤

1. 打开工具，确认“前台确认”为假、“自动管理开关”在日志中为假，磁盘边界计数为零。点击“确认当前会话”，应出现“用户点击确认前/后”，在当前控制台、DP 和闭锁满足时前台确认为真。
2. 队长自己锁屏。工具继续记录实际收到的信号与生产状态；无需在聊天发送密码或验证码。
3. 正常解锁回到桌面，先不要点击确认按钮。应保持未确认；唤醒、工作区活动、DP 恢复和普通应用激活不得自行创建新的确认请求。
4. 队长再点击“确认当前会话”。满足真实状态条件时确认恢复。若仍有 DP、睡眠或工作区闭锁，保留日志分析，不伪造正向通知或降低门槛。
5. 点击“结束观察”或正常关闭窗口。日志保留，主线程核对整个序列、撤销代数、请求与边界计数后，分别报告通过和待测项。

只锁屏/解锁不一定发生机器睡眠或切换用户。没有收到的类别保持待测，不能因为订阅了九类信号就写成九类全部验收通过。睡眠唤醒、切用户应在队长明确准备好时分别做，不由工具触发。

## 日志解释

界面显示前台确认、DP 闭锁、睡眠闭锁、工作区活动、撤销代数、待确认请求。记录同时包含真实 UID、控制台字典、真实 DP/应用活动快照、自动开关及磁盘边界计数。

九类真实接线为：应用激活、DP 即将不可用、DP 已可用、工作区会话失活、工作区会话活动、系统将睡眠、系统已唤醒，以及生产监控保留的两条非公开锁屏/解锁辅助信号。后两条不是 Apple 承诺的解锁权限接口，日志明确单独标注；DP 可用也不等于图形屏幕已解锁。

“真实信号到达”是观察回调发生时的快照；“信号后主执行器采样”是下一主执行器轮次的快照，不声称通知中心保证观察者固定执行顺序，也不代表系统原始事件产生顺序。周期采样只在状态变化时写入。

“前台确认”是生产模型内部存储状态，不代表允许实际挂载；此宿主自动管理始终关闭，磁盘边界也始终拒绝。`观察宿主关闭` 的最终清理会正常撤销确认，应与锁屏期间的撤销分开识别。

从启动开始最多观察十分钟，使用包含睡眠时间的连续时钟；若机器睡眠越过截止时刻，工具在恢复运行后的第一次检查结束。队长可以随时关闭工具。程序不会为验收自动激活自身、反复要求确认或重新打开窗口。

## 本机一次真实锁屏与解锁结果

2026-10-29，本机 macOS 26.6.2（25G83），36 条记录、约 172 秒。用户第一次手动确认成功；锁屏后观察到确认撤销、代数从 0 变为 1；解锁后至再次确认之间三次普通应用激活均未恢复确认；第二次手动确认成功；用户结束时清理并撤销至代数 2，未发现残留宿主进程。

全程自动管理关闭、磁盘事件监控不存在，磁盘读取和挂载尝试均为 0。构建清单中的 19 个输入源码无差异，签名产物哈希匹配。完整结构化断言、源指纹及时间点见本轮目录的 `结构化验收记录.json`、`本机真实观察验收.md`。

锁屏辅助信号在 70.309 秒被观察到，第一次撤销状态快照在 70.508 秒；约 199 毫秒只是观测间隔，不能称作生产处理延迟或竞态窗口。“信号后主执行器采样”也不保证所有生产观察者已完成，因此不能用它推断原始系统事件的总顺序。

本轮 DP 始终为真；实际只看到应用激活和两条非公开锁屏/解锁辅助信号。没有看到公开 DP、工作区切换或睡眠唤醒信号，不能宣称九类全部验收通过，也不能宣称仅靠公开接口完成所有锁屏检测。

可公开的结论限定为：在本机隔离宿主中，生产会话模型完成一次用户手动锁屏解锁后的撤销与显式重新确认验证；不等于正式安装应用、真实登录、系统睡眠、切用户、其他系统/硬件或实体盘验收。

限定结论是“本机真实睡眠/唤醒通知链与确认撤销行为通过”。两通知 UTC 均为 07:15:10Z，约 378 毫秒是宿主 uptime 的观测间隔，不能说成睡眠持续时间。近期 powerd 日志显示 15:15:10.453 接到系统将睡眠消息并关闭显示，10.617 出现活动提示后显示开启，10.750 更新唤醒结束时间；未证明深睡或持续时长，也没有明确证据将它认定为已取消。
