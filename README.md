## 它能帮你做什么

macOS自带的NTFS访问通常只能读取。NTFS畅写把查看状态、选择只读或读写、打开Finder、正常卸载和推出整盘放进一个原生界面。

- **看清当前状态**：磁盘在哪里、由谁挂载、能不能写；准备未完成时显示“写入未就绪”。
- **手动选择只读或读写**：系统和权限允许后，再到Finder中操作文件；其他驱动正在使用的卷不会被自动抢走。
- **记住每块盘的选择**：可为指定磁盘设置下次插入时只读或读写，自动管理默认关闭。
- **用完正常退出磁盘**：先同步、卸载，再按需要安全推出整盘；遇到文件占用或错误会停止，不强制处理。
- **查看和导出诊断**：设置、菜单栏和诊断入口集中呈现，长说明和底部按钮可以滚动查看。

“卷已卸载”不等于“整盘可以拔”。需要断开时使用安全推出，等待应用给出明确结果；固定USB硬盘推出后仍显示连接，也可能是正常状态。

## 0.3.1具体改了什么

1. **系统没列出扩展时，多一步正常核验。** macOS15.4起可由用户手动交给系统尝试挂载；明确关闭、查询报错或仍在等待时继续停止，自动挂载不会因此放行。这不等于扩展已经启用。
2. **不把“看起来能写”当作准备好了。** 需要内部准备的读写路径完成检查后才显示可写，刷新、重启或重新挂载不会沿用旧状态。
3. **写入前被拒，尽量保留原来的只读访问。** 原只读还在时，预检或身份检查失败会保留可读；已经关闭原只读或启动写入后发生的故障不在这个保证内。
4. **补齐旧系统的正常卸载收尾。** 区分系统保留的目录缓存和真实文件占用，处理同步、关闭错误，仍不强制卸载。
5. **设置更容易用，交付材料更完整。** 设置／诊断可滚动、可导出；修复源码首次构建及验收工具入口，提供对应源码与核验附件。

详见[0.3.1发行说明](发布/0.3.1兼容预览发行说明.md)。自动挂载来自0.2.0，Intel与旧系统运行路径来自0.3.0，这次没有把它们重新算作首次新增。

## 我的Mac能用吗

下表是当前实现和运行前置，不是“每种组合都已实机通过”的承诺。

| macOS | 使用方式 | 需要准备什么 |
| --- | --- | --- |
| 13～15.3 | 通过macFUSE兼容后端读写 | 自行安装并批准[官方macFUSE](https://github.com/macfuse/macfuse/wiki/Getting-Started)，配置管理员服务；Apple虚拟机不支持这条内核路径 |
| 15.4～26.3 | 只读用系统自带NTFS，读写用本应用的文件系统扩展 | 启用扩展并配置管理员服务；26.0～26.3实际系统仍未验 |
| 26.4及以上 | 只读／读写均用本应用的文件系统扩展 | 启用扩展；按磁盘权限使用管理员服务。本机26.6.2当前仍挂载失败 |

通用包包含Intel和Apple Silicon两种架构，但Rosetta执行不能代替Intel硬件验收。13／14虚拟机只完成安装、界面和限制提示等分项，兼容读写未通过；旧系统Apple Silicon使用macFUSE时，可能需要本人按官方流程批准组件和调整启动安全，本应用不会自动修改系统保护。

## 第一次怎么用

1. 从顶部下载DMG或ZIP，按同页`SHA256SUMS.txt`核对附件。把应用放在固定的“应用程序”目录；升级前先正常卸载卷、移除旧服务并退出旧应用。
2. macOS15.4起按应用诊断在系统设置启用文件系统扩展（FSKit）；13～15.3先准备官方macFUSE。模块没出现、不能启用或系统拒绝时，先查看已知问题，不反复强制挂载。
3. 需要管理员服务时，在设置的“物理磁盘挂载”中配置并按系统提示批准。已经由其他工具挂载的卷，先通过原工具正常卸载。
4. 在磁盘详情选择只读或读写，核对实际状态后打开Finder。完成后正常卸载；要拔盘时，再安全推出整盘并等待确认。

完整升级、权限与卸载顺序见[安装与卸载](发布/安装与卸载.md)。不要把密码发到聊天或Issue里，认证应在macOS自己的系统窗口完成。

## 想让选定的盘下次自动挂载

先确认手动流程适合你的环境，再启用这项可选功能：

1. 在磁盘详情的“下次插入此盘”里选择自动只读或读写。
2. 在设置的“插盘自动挂载”中打开“自动管理已选定的NTFS盘”，并“确认当前会话”。需要时再开启“登录时启动”。
3. 之后新插入该盘时，应用才按保存的选择处理。关窗继续运行，明确退出应用后停止；手动卸载后不会自动重挂。

发现其他磁盘驱动、身份不明或会话未确认时会暂停。锁屏／睡眠后不能沿用旧确认。当前没有20轮实体插盘、真实登录与跨账户全部通过的结论。
