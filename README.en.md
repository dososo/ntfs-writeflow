# NTFS 畅写 · NTFS WriteFlow

[完整介绍与截图](README.md) · [下载0.3.0兼容预览](https://github.com/dososo/ntfs-writeflow/releases/tag/v0.3.0) · [版本说明](发布/版本说明.md)

**0.3.1（构建10）候选尚未发布，下载仍为0.3.0。** 免费开源的macOS NTFS桌面应用，用中文界面呈现磁盘状态、只读／读写、Finder访问、正常卸载、整盘推出与后台管理。

Intel／Apple Silicon通用包、最低macOS13和macFUSE兼容前端来自0.3.0。0.3.1按模式选择后端：15.4～26.3只读使用系统原生NTFS、读写FSKit；26.4起两种模式均FSKit；13～15.3使用用户自行安装批准的官方macFUSE。FSKit及macFUSE使用随包NTFS-3G，系统原生只读不经过该引擎。15.4～26.3所有挂载请求经管理员服务；26及以上保留`funmount`卸载。

本轮五项变化：

- **旧FSKit同步访问**：修正旧系统模块发现和用户身份，旧协议子类取得资源同步访问能力；15.4～26.3只读使用系统原生NTFS，读写仍FSKit，26.4起两种模式均FSKit。
- **失败保RO与准确状态**：原只读仍存活时的资源／NTFS预检／身份拒绝保留可读；只有内核RW而内部未就绪时明确提示，刷新或重启不沿用旧成功。
- **本次挂载独立绑定**：内部准备证明绑定本次卷与介质，跨阶段许可一致；被动查询不启动写入，重挂不能套用迟到的旧证明。
- **根缓存停用收尾**：补旧系统漏卸载回调，区分FSKit保留的根缓存与真实非根占用；force／实际忙项仍拒，收尾原错锁存。新构建10的15.4受控镜像完整链与内部收尾已通过。
- **首次构建稳定与探针可复跑**：兼容源码先归档再解包；物理判定使用DA／IOMedia互证，缺失或冲突继续拒。验收工具给出完整构建命令和明确模拟／实际回放入口，不把模拟称实盘通过。

设置／诊断的滚动、长错误及导出可达已并入本版；Apple虚拟机13～15.3的macFUSE内核路径明确拒绝，特殊项和未知事务保护继续保留。13.7.4／14.0只有安装、界面和限制提示等分项，兼容VFS未通过。

构建10的根缓存收尾47项两架构、原四runner两架构、六目标严格检查及独审已通过；构建10已公证并在15.4安装，本次15.4受控镜像同包VFS及内部收尾已通过。构建9VFS工具退出0，但deactivate错误16仍使完整链失败；原重启登记中断另列。13.7.4／14.0安装、窗口与导出有分项，兼容VFS未通过；26.0～26.3仅策略／模拟回归。Intel实体机未验，Rosetta不代表Intel硬件，旧客体初始SIP disabled也不代表默认安全实体机。本轮发行基于206af70的475项冻结输入；App与DMG分别公证通过，21文件摘要／大小／权限一致，严格签名、Gatekeeper和stapler检查均退出0。构建10在macOS15.4（24E248）ARM客体的受控镜像完整链及内部sync0／close0／RO重开0已核验通过；本机实盘及最终源码分发仍待验。

旧FSKit的`nosuid`／`nodev`／`nobrowse`未全部保留；拒绝特殊项、不呈现setuid／setgid不证明内核安全标志生效。详情与失败历史见[发行草案](发布/0.3.1兼容预览发行说明.md)和[可核验说明](发布/0.3.1可核验说明.md)。Issue #3仍待原环境复测。

现代系统本轮改用本机macOS26.6.2与已授权5TB外部USB的一轮实际验收，文件写读／同步／占用拒绝／RO重挂结果尚待。不会额外启动26.4 VM；26.4仅处镜像准备，未启动、未通过。只读DA／IOMedia元数据验证不等于实盘文件操作成功。
