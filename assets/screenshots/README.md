# 应用截图

截图来自 0.1.1 候选应用的真实界面，不是设计稿。使用独立新建的 `WriteFlow Demo` 测试镜像；不包含个人文件列表、账户或真实物理介质名称。

- `main.jpg`：测试卷已由 `blntfs` 读写挂载，显示正常卸载与安全弹出整盘入口。
- `ejected.jpg`：GUI 整盘弹出成功，测试镜像从清单消失；系统映射与原设备随后独立核验消失。
- `settings.jpg`：菜单栏、刷新设置与已获系统授权的管理员服务。

展示用的设备编号及临时挂载路径只属于该次测试，不能复制为其他机器上的设备操作参数。固定 USB 硬盘的“安全推出但仍连接”语义另见安装说明；本组弹出截图使用的是磁盘镜像。
